En este curso aprenderas lo que es el lenguaje de CSS.

¿Qué es CSS?

Es uno de los lenguajes centrales de Internet. Mientras que para añadir texto a un sitio web se utiliza HTML y se estructura semantica, para definir el diseño del contenido se utiliza CSS. Es un lenguaje que permite definir la apariencia de los elementos HTML en una página web.

¿Qué aprenderé en este curso?

Aprenderemos a usar y dominar el lenguaje de css, sabremos el como usarlo en paginas web, así, como CSS permite controlar aspectos de diseño web como los colores, las tipografías, los márgenes y otros aspectos.

¿Qué es CSS GRID?

Es un sistema de maquetación en dos dimensiones (filas y columnas) para la web que permite organizar y posicionar elementos de forma sencilla, flexible y adaptable. Controla el espacio tanto en horizontal (columnas) como en vertical (filas) al mismo tiempo.
